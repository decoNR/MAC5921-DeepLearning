\section{Experimentos}

Essa seção descreve os experimentos realizados (incluindo o planejamento) e apresenta os resultados obtidos.

\hypertarget{explicacao-dinamica-loss}{}Analisarei o valor da função de perda e da acurácia para os conjuntos de treinamento e validação ao longo do treinamento. É importante mencionar que, para o conjunto de treinamento, o valor final é uma média dos valores que são calculado para cada batch com os pesos atuais da rede (atualizados após cada batch), ou seja, cada valor de loss/acc é calculado para rede com pesos diferentes dentro de uma mesma época. Já para o conjunto de validação, o valor é calculado com os pesos congelados ao final da época.

\subsection{Aspectos gerais}
