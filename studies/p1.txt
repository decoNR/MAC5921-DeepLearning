# Requisitos

- Modelos de Classificação: predizem entre um grupo de classes qual é a classe associada ao input
    - Classificação linear: divide o espaço por hiperplanos e prevê as classes baseadas em qual "lado" do hiperplano o ponto associado ao input está.
    - Regressão logística (utilizada para classificação após definir um threshold): calcula z = w·x + b e aplica a sigmoide σ(z) = 1/(1+e^(-z)), obtendo P(y=1|x) ∈ (0,1); treinada minimizando a entropia cruzada (máxima verossimilhança). A fronteira de decisão é um hiperplano, logo é um classificador linear. Para várias classes usa-se softmax.
- Modelos de Regressão: predizem um valor contínuo para um dado input
    - Regressão Linear: encontra o hiperplano que melhor se ajusta aos dados (ex.: minimizando o erro quadrático médio); dado um input, a previsão é o valor correspondente a esse input no hiperplano.
- Teorema de Bayes: atualiza uma probabilidade dado um fato observado, restringindo o espaço amostral aos casos em que o fato ocorre.
- Modelos gerativos / discriminativos: gerativos modelam como os dados são gerados (P(x|y) e P(y), ou P(x,y)), podendo gerar novos exemplos; discriminativos modelam diretamente P(y|x) (ou a fronteira de decisão) para decidir uma classe ou valor para um input.
- MSE / MAE : erro quadrático médio e erro absoluto médio, funções de custo para regressão.
    - MSE: penaliza muito erros grandes (sensível a outliers); diferenciável em todo ponto.
    - MAE: penaliza erros linearmente (mais robusto a outliers); não diferenciável em 0.
- Regularização: técnicas para reduzir overfitting (melhorar generalização), em geral restringindo a complexidade do modelo, por exemplo adicionando à função de custo uma penalidade sobre os pesos (com pesos grandes pequenas mudanças no input geram resultados muito diferentes): L = L_dados + λ·R(w), com λ controlando o trade-off viés/variância.
    - L2 (Ridge / weight decay): R(w) = Σ w_j²; encolhe todos os pesos em direção a 0, sem zerá-los.
    - L1 (Lasso): R(w) = Σ |w_j|; tende a zerar pesos (solução esparsa, seleção de features).
    - Outras: dropout, early stopping, data augmentation.
- Ensembles: combinam as previsões de vários modelos (votação/média) para obter um modelo melhor que cada um isoladamente.
- Estimar melhores hiperparâmetros (e o desempenho em dados não vistos):
    - Hold-out validation: separa os dados uma única vez em treino / validação / teste; treina no conjunto de treino, escolhe hiperparâmetros e modelos pelo desempenho na validação e reporta o desempenho final no teste (usado só no fim). Simples e barato, mas a estimativa depende de qual divisão foi sorteada e desperdiça dados (bom quando há muitos dados).
    - Cross validation: (k-fold) divide os dados em k partes (folds); treina k vezes, cada vez usando uma parte diferente como validação e as outras k-1 como treino, e tira a média do desempenho. Estimativa mais confiável (menor variância) e usa todos os dados para treino e validação, mas custa k treinos (bom quando há poucos dados; menos usado em deep learning pelo custo).
- trade-off viés/variância: aumentar a complexidade do modelo reduz o viés e aumenta a variância.


# Redes Neurais

- Normalização: colocar os valores numa escala comum (ex.: média 0 e variância 1) para estabilizar e acelerar o treino.
    - Normalizar os inputs faz com que a rede não propague mais sinais (e gradientes maiores) somente pq uma feature tem escala maior.
    - Batch normalization: mesma ideia de normalizar o input, mas aplicada dentro da rede, na entrada de cada layer.
        - Problema: como os pesos das camadas anteriores mudam durante o treino, a escala dos valores que chegam em cada layer fica mudando, e o layer fica "correndo atrás" de um alvo móvel.
        - Solução: para cada neurônio, pega os valores do batch atual, subtrai a média e divide pelo desvio padrão.
        - Depois multiplica por γ e soma β (aprendidos), para a rede escolher a melhor escala: y = γ·(h - μ_batch)/σ_batch + β.
        - Na inferência (pode haver só 1 exemplo) usa a média e o desvio acumulados durante o treino.
        - Resultado: treino mais rápido e estável (permite learning rates maiores) e leve efeito regularizador.
    - Normalização (z-score) não muda a forma da distribuição: só desloca e reescala (assimetria, picos e outliers se mantêm; não vira gaussiana).
- Otimizador: como atualizar os pesos da rede dado um certo gradiente.
- Viés indutivo: suposições que o modelo faz sobre os dados que guiam a modelagem. É o conjunto de suposições e premissas que o algoritmo de aprendizado utiliza para fazer previsões.


# CNN 

- Convolução: 
    - Detectar padrões aprendidos pelos kernels.
    - 1x1 ou "point wise": combinação linear entre os canais de cada pixel (mesma posição espacial); usada para mudar o nº de canais. Aplicar um kernel por canal sem combiná-los é a "depthwise convolution"; depthwise + pointwise = "depthwise separable".
    - Kernels podem ser usados para fazer upsampling também. Nesse caso também podem ser treinados pela rede. É chamado também de "transposed convolution"
- Stride: número de pixels que a convolução pula ao passar pela imagem
- Feature map: output de layers intermediários da rede. No caso de convoluções elas também são imagens e são os sinais que a rede "deixou passar" após as camadas. Cada filtro gera um feature map.
- Inception: utiliza diferentes tamanhos de kernel em um mesmo layer. Intuitivamente a rede tem a oportunidade de "usar" diferentes tamanhos de filtros. As saídas dos ramos são concatenadas.
- Transformações residuais: criar uma "skip" connection (y = F(x) + x) de modo a facilitar a rede a aprender transformações de identidade (basta F(x) = 0). Ajudou a treinar redes com mais camadas sem degradação do resultado. Pode se dizer que ajuda no flow do gradiente também.
- Dropout: "desligar" uma porcentagem aleatoria dos neurônios da rede. Intuitivamente isso força a rede a ser mais resiliente ("usar caminhos alternativos" em predições semelhantes).
- Segmentação de imagem: 
    - Sliding window: patches são recortes da imagem que são utilizados para classificar cada pixel.
    - Gerar a imagem segmentada com uma CNN construíndo a imagem segmentada a partir das features geradas pela rede. Unet é uma arquitetura que funcionou nesse caso (possui skip connections). É um exemplo de encoder-decoder. De forma mais genérica, pode ser usada para problemas de tranformação imagem para imagem.
    - Além de usar loss considerando erro pixel a pixel também se utiliza IoU.
- Detecção de objetos: 
    - YOLO: um estágio; divide a imagem em grade e cada célula prevê caixas (regressão) e classes numa única passada. Mais rápido, porém menos preciso em objetos pequenos (v1).
    - R-CNN: detecção em dois estágios. Primeiro extrai regiões que provavelmente tem algum objeto (selective search, ~2000) e depois cada região passa pela CNN para obter a classe e o ajuste da caixa.
        - Lento pois muitas regiões se intersectam e os calculos são repetidos para esses casos. 
        - Fast R-CNN: passa a imagem inteira uma vez pela CNN; projeta as propostas (RoI = Region of Interest, região candidata) no feature map; RoI Pooling converte cada uma para tamanho fixo; FC → classe + ajuste da caixa.
        - Faster R-CNN: troca o selective search por uma Region Proposal Network (RPN) sobre o mesmo feature map; usa anchors (escalas/proporções) e prevê objectness + ajuste da caixa. Tudo aprendido, quase tempo real.
- Precision recall curve: precision = TP/(TP+FP), recall = TP/(TP+FN); varia-se o threshold de confiança (alto → mais precision, menos recall). AP = área sob a curva; mAP = média do AP entre classes. Em detecção, TP exige IoU ≥ limiar (ex.: 0.5).


# Explainable AI 

- Oclusão (occlusion sensitivity): cobrir partes da imagem e ver o quanto a predição muda; queda grande → região importante.
- Attribution map / mapa de saliência: busca entender qual parte da imagem é mais relevante para a predição. Derivada do score da classe em relação a cada pixel.
- Integrated gradients: resolve o problema do gradiente ser ~0 em regiões flat (saturação). Integra os gradientes ao longo do caminho de uma baseline (ex.: imagem preta) até a imagem real.
- CAM (Class activation map): mapa de calor = soma dos feature maps da última conv ponderados pelos pesos da classe na camada final. Exige arquitetura conv → global average pooling → FC (às vezes retreino).
    - Grad-CAM: os pesos de cada canal vêm da média dos gradientes do score da classe em relação ao feature map (+ ReLU). Funciona em qualquer CNN, sem mudar a arquitetura nem retreinar.


# RNN 

- Beam search: não é uma RNN, é um algoritmo de decodificação usado na inferência de qualquer modelo autoregressivo (decoder RNN, Transformer, LLM). Em vez de escolher só o token mais provável a cada passo (greedy), mantém as k sequências parciais com maior probabilidade acumulada (soma dos log-probs) e no fim escolhe a melhor. k = 1 equivale ao greedy.
- Attention em RNNs (tarefas seq2seq): em vez de comprimir a frase toda num único vetor de contexto (gargalo), a cada passo t o decoder calcula um contexto próprio c_t = Σ α_{t,i}·h_i, uma média ponderada dos estados h_i do encoder, focando nos tokens de entrada mais relevantes para aquele passo.
    - Função de alinhamento: é o score e_{t,i} = a(s_{t-1}, h_i), que mede o quanto o estado do decoder s_{t-1} "combina" com cada h_i. Os pesos são α_{t,i} = softmax_i(e_{t,i}). A forma é escolhida; se tiver parâmetros (ex.: aditiva vᵀ·tanh(W·s + U·h)) eles são aprendidos, senão (produto escalar, cosseno) a rede aprende os próprios s e h. A matriz de α mostra o alinhamento entre as palavras de origem e de destino.


# Tokenização

- WordPiece: tokenização por subpalavras parecida com o BPE (usada no BERT). Também junta pares iterativamente, mas escolhe o par que mais aumenta a verossimilhança do corpus (score = freq(ab) / (freq(a)·freq(b))), e não só o mais frequente. Pedaços no meio da palavra recebem o prefixo "##" (ex.: "playing" → "play" + "##ing").
- BPE (Byte Pair Encoding): tokenização por subpalavras. Começa com o vocabulário de caracteres (ou bytes) e, repetidamente, junta o par adjacente mais frequente no corpus num novo token, até atingir o tamanho de vocabulário desejado. Para tokenizar texto novo, aplica as junções aprendidas na mesma ordem.
    - Meio-termo entre caracteres (sequências longas) e palavras (vocabulário enorme, palavras desconhecidas): palavras comuns viram 1 token, raras são quebradas em pedaços (ex.: "desconhecido" → "des" + "conhec" + "ido"). Nunca há token desconhecido (no pior caso cai em caracteres/bytes). Usado no GPT.


# Transformers

- Elimina recorrência: os tokens não são processados em sequência, e sim todos em paralelo. Como a ordem se perde, soma-se um positional encoding aos embeddings.
- Introduz self-attention: cada token "olha" para todos os tokens da mesma sequência e monta sua nova representação como média ponderada deles (atenção da sequência consigo mesma).
    - Cada token gera 3 vetores por projeções aprendidas: Q = XW_Q (query), K = XW_K (key), V = XW_V (value). X é a matriz T × d com uma linha por token.
    - Attention(Q, K, V) = softmax(QKᵀ / √d_k)·V: o score é o produto escalar query·key (função de alinhamento); √d_k evita valores grandes que saturam o softmax.
    - Multi-head: várias atenções em paralelo com projeções diferentes (cada uma captura um tipo de relação), concatenadas no fim.
    - No decoder usa-se máscara causal (token só vê os anteriores). Essencial no treino, em que cada posição t prevê o token t+1 em paralelo e não pode ver a resposta. Na inferência também é usada quando o prompt é processado de uma vez; ao gerar token a token, o futuro ainda não existe.
- Positional encoding: vetor somado ao embedding de cada token indicando sua posição (sem ele a self-attention não distingue ordem: "cão morde homem" = "homem morde cão").
    - Senoidal (original): PE(pos, 2i) = sin(pos / 10000^(2i/d)), PE(pos, 2i+1) = cos(...); fixo, cada dimensão com uma frequência diferente.
    - Aprendido (BERT, GPT-2): um embedding por posição, treinado. Variantes atuais codificam posição relativa (ex.: RoPE).
- BERT (Bidirectional Encoder Representations from Transformers): Transformer só com encoder (sem máscara causal, cada token vê o contexto dos dois lados). Serve para gerar representações contextualizadas de texto, não para gerar texto.
    - Pré-treino auto-supervisionado: Masked Language Modeling (esconde ~15% dos tokens e prevê quais eram) + Next Sentence Prediction (a frase B segue a A?).
    - Depois faz fine-tuning em tarefas específicas (classificação, análise de sentimento, NER, perguntas e respostas), geralmente usando a saída do token especial [CLS] para classificação.
